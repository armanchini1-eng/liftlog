LiftLog — offline workout tracker (PWA)

This folder is the whole app. Upload ALL files in it (not the folder's parent) to any
static web host that serves HTTPS, then open the address in Safari on your iPhone and
use Share > Add to Home Screen.

Files: index.html (the app), sw.js (offline support), manifest.webmanifest,
icon-192.png, icon-512.png, apple-touch-icon.png

Data lives only on the device (IndexedDB). Use Settings > Export backup regularly.
